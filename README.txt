EXPENSE TRACKER V4

Major additions:
- User accounts and private data
- Modern responsive dashboard
- Dark mode
- Savings goals
- Loan and EMI tracking
- Recurring transaction planner
- Monthly budgets
- Reports and CSV export
- SQLite backup download
- Search/filter/edit/delete transactions
- Custom categories

Run:
1. Extract to C:\xampp\htdocs\expense_tracker_v4
2. Start Apache in XAMPP
3. Open http://localhost/expense_tracker_v4/register.php
4. Create your account.

Requirements:
- PHP 8+
- SQLite PDO extension
- Apache/XAMPP

Security note:
This is suitable as a local project. Before public deployment, add HTTPS, CSRF protection, secure cookie settings, login rate limiting, stronger authorization checks, automated backups, and server hardening.
